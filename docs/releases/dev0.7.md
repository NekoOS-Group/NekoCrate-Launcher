猫咪盒子启动器 dev0.7，应用版本 `0.7.0-dev.1`。

## 加载器与整合包安装

- 普通游戏下载界面统一选择原版、Fabric、Forge 或 NeoForge，并按游戏版本列出兼容的加载器版本。
- 加载器版本列表使用一小时磁盘缓存；切换时优先展示已有列表，刷新失败仍保留缓存，当前会话记住所选版本。
- 普通加载器和整合包共用安装流程，支持旧版 Forge 和现代安装器处理器；暂停会停止当前处理器，继续后复用已完成步骤。
- 支持导入 Modrinth `.mrpack` 和 CurseForge 整合包，在所选游戏目录的 `versions/<名称>` 内保存 Mods、配置、存档、安装清单及断点数据。同名目录报错，已有目录继续原地关联。
- CurseForge 官方解析保留 API Key 配置入口；作者限制分发的文件支持手动补齐。未完成安装的声明内容也能在版本管理中查看。
- 整体安装进度与单个文件、安装器阶段进度分开，避免单个阶段完成时误显示为整体接近完成。

## 版本管理与交互

- 元数据页按原始文件展开游戏版本、加载器、Java、启动入口、整合包声明等信息，支持查看原始内容。
- Mods、数据包、资源包和存档可展开元数据；Mods 展示适用游戏版本、依赖及兼容信息，支持依赖跳转和在文件管理器中选中文件。
- 未安装整合包区分声明的 Mods、资源包、待解析文件和运行依赖；数量为零的内容页自动隐藏。
- 内容列表分批加载并缓存摘要，改善首次加载、切页与列表进出动效；数量变化保留计数器过渡。
- 游戏目录较多时保留八个图标和展开入口，折叠区支持拖拽换位；新建和导入的普通目录使用随机图标。
- 下载界面标题栏紧凑显示新目录的名称、图标与位置，版本管理和下载目标切换使用一致的过渡。
- 优化 Microsoft 设备授权布局；新授权会终止上一轮等待，验证码自动复制。
- 改进自动 Java 选择与已有运行时复用。

## 网络错误与诊断

- HTTPS 证书过期或尚未生效时明确提示检查系统日期、时间、时区及自动同步，避免把时间问题一律显示为普通网络失败。同一证书错误不再反复重试；其他下载源仍单独验证。
- 更新失败保留底层错误原因并进入界面日志。更新、下载、启动、登录等失败写入启动器数据目录的 `logs/launcher.log`，包含系统时间、时区偏移、操作与错误原因链。
- 日志对令牌、密码及 URL 签名参数脱敏；单文件约 1 MiB，保留三份轮转文件。校准时间后可重新检查更新或继续下载，已保留的下载片段不会因证书失败而清空。
- 内存中的加载器缓存改用单调时钟，避免修改系统时间干扰有效期。磁盘缓存仍按文件时间判断，异常时间戳视为过期并允许回退已有缓存。

## 安装与更新

- 提供 macOS Apple Silicon DMG、Windows AMD64 EXE、Linux AMD64 AppImage / DEB，以及 macOS 自动更新包 `.app.tar.gz`。
- dev0.5、dev0.6 安装版可通过应用内更新升级；开发模式和 Linux DEB 使用手动安装。
- 更新包继续验证数字签名及版本；签名内嵌于 `latest.json`，SHA-256 校验清单保存在 `BUILDINFO.json`。
- 发布复用通过 CI 的前端产物、跨版本 Rust 缓存和预装依赖的 Linux 构建镜像。

这是预发布版本。系统时间错误仍需在系统设置中校准，启动器不会关闭 HTTPS 证书验证或修改系统时间。完整加载器安装尚未完成三平台实机游戏验证；macOS 包未公证，Windows 包未做发布者签名。
