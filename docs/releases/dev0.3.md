猫咪盒子启动器 dev0.3，应用版本 `0.3.0-dev.1`。

## 下载

| 平台 | 安装包 |
| --- | --- |
| macOS Apple Silicon（M1 及更新芯片） | `mac-appsilicon.dmg`、`mac-appsilicon.app.zip` |
| Windows AMD64（Intel / AMD 64 位） | `win-amd64-setup.exe` |
| Linux AMD64（Intel / AMD 64 位） | `linux-amd64.AppImage`、`linux-amd64.deb` |

文件名均以 `NekoCrate-Launcher-dev0.3-` 开头。`SHA256SUMS` 提供安装包校验值，`BUILDINFO.json` 记录源代码提交、版本和目标架构。

## 本版变化

- 下载支持暂停／继续和 HTTP Range 字节级续传，中断后保留已接收数据；下载源不支持续传时安全重下对应文件。
- 下载面板按安装流程展示阶段与逐文件进度，下载中的文件置顶；暂停／继续和取消按钮位于固定标题栏。恢复任务时计入已有文件和断点字节，阶段切换不清零。
- 持久化完整文件的校验记录，未变化文件复用结果，文件变化或记录失效时重算哈希；手动「校验修复」仍执行完整检查。恢复历史进度不再扫描全部文件内容。
- 官方版本目录优先命中本地缓存；不支持的本地加载器版本提前说明，错误统一显示于主界面右上角。
- 已有 `.minecraft` 目录直接关联并在原路径读取、下载和修复，不再复制到启动器目录。以前已复制的实例保留原有数据，可重新关联原目录；移除关联实例不会删除原目录。
- 全局设置即时保存，新增「关于」页面；Java 改为自动、探测结果及文件选择列表。下载期间可编辑其他实例，完成下载不会误关闭设置。
- 游戏本体与 Mod 下载源分开设置；增加自动选择、自适应并发、系统／HTTP／SOCKS5 代理及可选代理认证。代理密码保存在系统凭据存储。
- 更新原版方块素材、实例图标切换动效、待下载版本进度图标和皮肤键盘选中描边；改善下拉菜单裁切、弹窗尺寸过渡和焦点样式。
- 启动器代码改用 GPL-3.0-only；第三方依赖与 Minecraft 素材保留原权利声明。
- 发布流程共享一次前端构建，每个平台只执行一次原生 release 编译；源码检查留在普通 CI，保留发布版本、架构与安装包校验。

## 升级与已知限制

- dev0.2 及更早版本的更新检查可能无法识别 `dev0.3`，请从本页下载安装；本版已支持通用 `devX.Y` 标签解析。当前更新功能提供安装包链接，不自动替换程序。
- 旧缓存首次使用需要建立校验记录，之后可复用；显式修复仍需完整读取文件。断点续传取决于下载源的 HTTP Range 支持。
- 微软登录仍需有效的 Microsoft Client ID，并满足 Minecraft API 访问要求；可不登录，以本地 Player 身份启动游戏。
- 当前支持官方原版 Java Edition 的安装与启动，尚不支持 Forge/Fabric 等加载器及整合包安装；Mod 下载源设置不代表已实现 Mod 浏览、下载与安装。
- macOS 包使用 ad-hoc 签名，未做 Apple 公证；Windows 包未做发布者代码签名。Linux AppImage 需要执行权限，部分发行版还需要 FUSE 2。
- 三平台自动化构建与测试不等同于所有功能已完成实机验收。Minecraft 素材归 Mojang Studios / Microsoft 所有，本项目不是 Minecraft 官方产品。
