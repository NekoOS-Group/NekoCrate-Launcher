猫咪盒子启动器 dev0.8，应用版本 `0.8.0-dev.1`。

## 添加版本、整合包和资源

- “添加新的版本”统一游戏版本、整合包和资源入口，共用目标游戏目录选择。
- 支持在线搜索 Modrinth / CurseForge 整合包，选择版本、下载并预览安装内容。CurseForge 官方文件解析仍需在网络设置中配置 API Key。
- 支持向所选版本安装 Mods、资源包、数据包、光影和地图，也可直接拖入本地文件或文件夹。
- 安装前检查游戏与加载器兼容性、必要依赖和文件冲突；文件放入所选版本实际使用的目录，不覆盖内容不同的已有文件。
- 支持下载暂停、缓存复用和中断后继续安装；保存资源来源与安装计划，方便查看和继续处理。

## 界面与动效

- 统一版本管理、实例设置、账户、日志、添加版本和资源界面的出现、退出及切换动效；启动器打开时，界面控件也按统一节奏出现。
- 优化虚拟列表的动效与日志滚动同步，避免新增日志或滚动时重复播放列表入场动画。
- 资源文件名用于展开详情，底部目录增加文件夹图标并可点击打开。
- 账户选择改为白色头像高亮，移除外部选中方框，名称仅在悬停或键盘聚焦时显示。

## 登录与依赖优化

- 登录成功后立即更新账户，减少额外状态查询和浏览器回调等待；修复较早返回的状态覆盖新登录账户的问题。
- 合并头像和皮肤模型的重复请求，复用纹理缓存，避免刷新凭据时重复加载皮肤。
- 精简剪贴板、ZIP、TOML、内存查询、时间和哈希相关依赖及功能开关；保留文本剪贴板、平台内存检测、压缩包处理和文件校验能力。

## 安装与更新

- 提供 macOS Apple Silicon、Windows AMD64、Linux AMD64 安装包和自动更新产物。
- 沿用同一提交只执行一次完整 CI、发布复用前端产物与 Rust 缓存的构建流程。
