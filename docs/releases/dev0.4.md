猫咪盒子启动器 dev0.4，应用版本 `0.4.0-dev.1`。本版接续 dev0.3.2，不发布 dev0.3.3。

## 渲染与响应性能

- 背景改为 GPU 批量绘制：几何数据常驻，每帧一次属性上传、一次实例化绘制，避开逐 SVG 节点修改以及逐 Canvas 路径转换、填充和描边的开销。
- 保留五种主题图案、300 ms 马尔可夫转移、线宽与颜色平滑、染料扩散、漂移速度及设备像素密度。弹窗打开时背景继续运行，不降低帧率或清晰度。
- 完整图的状态持续推进，不暂停不可见格子的模拟；上下文丢失可恢复，不支持所需 GPU 能力时自动回退至 Canvas 2D。
- 去除每帧数值转字符串再解析的开销，保留原有舍入边界与数值精度。
- 下载明细按阶段维护状态索引，文件进度变化不再反复扫描整个文件表；下载中文件置顶、稳定顺序和虚拟滚动行为保持不变。
- 日志缓存避免逐索引的响应式移动，保留原有日志内容、顺序、截断、复制与清空行为。

本机 M4 Pro 开发模式的可见窗口短时采样中，Graphics and Media 平均 CPU 由中间 Canvas 方案的约 17% 降至 GPU 批量方案的约 6%；这是 CPU 观测，不是 GPU 利用率或跨平台性能承诺。图形跨渲染器的边缘抗锯齿存在细微像素差异，模拟、颜色与布局保持一致。验证方法见仓库 `docs/performance/dev0.4.md`。

## 安装与更新

- 保留 dev0.3.2 的 Windows 前端嵌入修复，以及发布过程的跨版本 Rust 缓存复用。
- Linux CI 与打包统一使用 Ubuntu 官方 HTTPS 软件源，避开本次 Azure 镜像下载停滞；增加连接超时和重试限制，依赖与检查项目保持不变。
- macOS Apple Silicon：DMG / app ZIP；Windows AMD64：EXE；Linux AMD64：AppImage / DEB。
- 从 dev0.3.2 的全局设置「启动器版本」检查更新，应识别 dev0.4，并打开对应平台安装包的下载入口。安装仍需手动完成，不会自动替换正在运行的应用。
- 保留实例、账户和设置，没有游戏目录迁移。macOS 为临时签名、未公证；Windows 无发布者签名。
