# dev0.9.7

改进整合包与资源浏览、项目图文介绍和本地资源详情，并修复中断安装后无法继续的整合包元数据问题。

## 浏览与安装

- 整合包与资源列表改为滚动加载，整合包支持来源、排序和分类筛选；点击列表中的分类标签即可加入筛选，已选标签反色显示。
- 搜索与筛选收纳到标题区域，精简添加版本、整合包详情和资源预选界面的重复入口与说明。
- 整合包详情默认使用最新可用版本，点击标题旁的版本文字才加载版本列表；版本、游戏版本、加载器与更新时间集中展示，下载入口改为标题行图标。
- 列表补充图标、作者、下载量与分类标签；详情支持 Markdown / HTML 长介绍、可自动播放的图片轮播、图片预览，以及合并的项目、源码、文档、反馈与许可链接。

## 资源详情

- 版本管理与资源管理支持显示 Mods、资源包和光影的真实图标，优先读取包内图片，没有内嵌图片时使用已关联在线项目的图标。
- Mod 图标与状态操作合并：正常显示代表已启用，禁用与待下载状态覆盖对应标记，点击仍可切换启用状态或下载。
- 已关联 Modrinth / CurseForge 项目的本地资源可以展开长介绍、作者、图片与链接；资源包显示包格式、支持范围与 README，光影显示 README、配置档位及声明的 Iris 功能要求。
- 包内 Markdown 说明支持格式化阅读，元数据与说明原文仍可查看；缺少元数据的资源不显示空展开入口。
- 可见项按需读取图标，限制并发并复用缓存；在线图片与介绍也复用缓存，避免反复打开列表时重复请求。

## 修复

- 修复包括 ATM9 在内的未完成整合包，其清单误占启动配置路径后持续出现“版本元数据与所选版本不一致”的问题；只恢复与保存的安装记录完全一致的清单，保留正常版本配置的校验。
- 统一光影名称与文件信息的两行布局，保留资源列表展开和切换动效。

继续提供 macOS Apple Silicon、Windows x64、Linux x64 的安装版与便携版，沿用现有自动更新签名验证与更新通道。
