猫咪盒子启动器 dev0.6，应用版本 `0.6.0-dev.1`。

## 版本管理

- 在「下载新的版本」右侧新增「管理版本」入口。左栏显示版本名称、游戏与加载器版本，集中提供改名和删除；右侧按 Mods、数据包、材质包、存档分页展示。
- 打开管理界面或切换版本时，提前统计所有页签的数量，显示为 `Mods(数量)` 等；统计不解析 Mod JAR 元数据。刷新位于标题栏实例名称后，搜索位于右下角，与目录路径同行。
- 列表读取该版本实际使用的游戏目录，支持整合包隔离目录、HMCL 自定义目录和旧版 Forge 的版本专用 Mods 子目录。数据包同时检查游戏目录及各存档的 `datapacks`。
- 改名保留真实版本 ID 和文件夹；删除前检查版本依赖，版本文件移入原游戏目录内的回收区，共享 Mod、资源和存档保留。游戏运行或安装任务进行时不能删除版本。

## 添加游戏目录与下载安装

- 添加界面自动发现官方启动器目录和可执行文件旁的 `.minecraft`，可直接关联、选择已有文件夹，或在启动器数据目录／外部位置新建。
- 官方启动器目录默认命名为「官方启动器」，保留草方块图标；新建目录预填默认名称，界面提示可拖拽文件夹导入。已有游戏目录继续原地关联。
- 下载界面扩大，标题栏可切换目标游戏目录或新建目录；版本浏览器支持正式版、快照版、开发版、愚人节版筛选，类别使用不同方块图标与颜色。
- Fabric 使用同一行的开关和版本选择。先检查兼容版本目录，不支持的游戏版本自动关闭 Fabric，不再反复请求必然返回 HTTP 400 的接口。

## Windows 修复

- Java 探测和游戏启动使用隐藏控制台的进程创建方式，启动游戏优先使用同一运行时内的 `javaw.exe`，保留日志采集。
- 传递给 Java 的路径去除 Windows 扩展路径前缀，修复含中文路径的 Forge 整合包启动参数问题；运行日志兼容系统代码页输出。
- 修正旧版 Forge／RLCraft 对空 LWJGL 平台占位 JAR 的检查，避免将已安装版本误判为需要下载或不支持修复，同时保留真正含有 Java 类的依赖。
- CI 增加 Windows 进程、启动路径及版本管理回归检查。

## 安装与更新

- 提供 macOS Apple Silicon DMG、Windows AMD64 EXE、Linux AMD64 AppImage / DEB，以及 macOS 自动更新包 `.app.tar.gz`。
- dev0.5 安装版可通过应用内更新升级；开发模式和 Linux DEB 使用手动安装。dev0.4 及以前版本需手动安装一次。
- 签名内嵌于 `latest.json`，文件大小与 SHA-256 统一记录在 `BUILDINFO.json`；不再单独提供 `.sig`、`.app.zip` 或 `SHA256SUMS`。
- 发布复用同一提交通过 CI 的前端产物、跨版本 Rust 缓存和预装依赖的 Linux 构建镜像。

Forge / NeoForge 本阶段仍支持启动已有安装，尚不提供其安装器。macOS 包采用临时签名，未公证；Windows 包未做发布者签名。
