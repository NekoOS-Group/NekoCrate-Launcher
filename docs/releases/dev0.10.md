# dev0.10

本次更新扩展商城的资源类型和皮肤来源，统一浏览与筛选布局，并完善首页小组件。应用版本为 `0.10.0-dev.1`。

## 商城与资源浏览

- 商城可直接切换整合包、Mods、资源包、数据包、光影、插件、服务器、地图和皮肤。
- 插件支持浏览 Modrinth 和 CurseForge 项目并下载文件；地图支持浏览、搜索及下载 CurseForge 项目。
- 新增 Modrinth 公共服务器列表，可查看详情、复制地址或收藏到首页服务器列表。
- 服务器和地图提供分类标签筛选；插件可按来源、游戏版本和加载器筛选。
- 整合包、插件、服务器和地图使用统一列表布局，展示图标、作者、下载量及标签。
- 搜索框和筛选控件统一排列在同一行，资源分类移入标题栏；修复切回整合包时搜索框与下拉菜单重叠的问题。

## 皮肤来源

- 接入 LittleSkin、Ely.by、MinecraftSkins.net 和 MineSkin，默认使用 LittleSkin，移除 NameMC 入口。
- 支持搜索、滚动加载、皮肤模型预览和下载到皮肤库；Ely.by 按皮肤标签搜索。
- 下载保留皮肤名称和手臂模型，复用目录与纹理缓存，相同皮肤重复下载时合并为已有条目。
- 本地 PNG 导入继续保留，无需为这些皮肤来源配置账户或 API Key。

## 首页与小组件

- 实例栏新增滚轮选择样式：平时显示当前实例，悬停后展开，滚轮切换时当前方块保持位置，边缘选项淡出。
- Trends、服务器列表和最近存档支持左右对齐、调整高度及贴边收起；收起行为可在布局编辑中设置。
- 移除收藏版本小组件，修复一言控制栏悬停抖动，改善编辑时的图层与布局操作。
- 最近存档可点击直接启动进入；不支持直接进入的旧游戏版本会说明限制。

## 官网
