# dev0.9.6

改进 Java 发现与兼容匹配、启动失败后的处理入口，并重新整理添加版本与资源预选流程。

## 添加版本与资源

- 正式版、快照版、开发版、愚人节版与整合包入口合并为同一栏，用竖线区分整合包。
- 加载器下方的资源入口支持多选 Mods、资源包和光影，按待安装的游戏版本和加载器筛选兼容版本；预选时不会安装到已有版本。
- 确认后先安装游戏和加载器，再安装预选资源及必要依赖；公共依赖去重，文件与兼容性冲突在写入前检查。
- 预选记录随版本保存在游戏目录，取消、失败或重启后可继续；资源未完成前不会把版本标为安装完成。更换游戏版本或加载器时清空旧预选，避免安装不兼容资源。
- 进入具体整合包后隐藏下载源选择框，版本选择移至整合包标题旁。

## Java 与启动

- 扩大 Java 搜索范围，覆盖更多系统安装位置、环境变量、常见启动器与运行时目录；探测结果按文件状态缓存并去重。
- 统一自动选择与手动选择的兼容性判定，保留加载器的必要限制，复用同一游戏配置曾成功使用的 Java，减少重复下载运行时。
- 启动失败也会保存诊断与日志；日志内按原因提供选择 Java、调整内存、管理 Mods、修复文件和打开报告等入口。
- 启动中按钮采用与运行中一致的方形实心状态，显示“启动中”，去掉旋转圆圈。

继续提供 macOS Apple Silicon、Windows x64、Linux x64 的安装版与便携版，沿用现有自动更新签名验证与更新通道。
