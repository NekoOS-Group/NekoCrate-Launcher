猫咪盒子启动器 dev0.9，应用版本 `0.9.0-dev.1`。

## 资源与版本管理

- 新增全局资源管理，集中查看 Java、游戏资源、皮肤与缓存；共享目录中的文件只统计一次。
- Mods 支持点击状态图标启用／禁用，切换状态时保留排序；支持查看和编辑关联配置，提供 JSON、TOML、CFG 高亮与编辑辅助，保存时备份原文件。
- Mods、资源包和光影可拖入其他版本；启动版本支持拖拽排序和拖至右上角移除。删除版本改用系统废纸篓／回收站。
- 完成安装后自动删除下载暂存；暂停、失败及未完成安装保留进度，对应版本移除时清理其暂存。本地已有且索引有效的资源可直接复用。

## 下载与启动

- 下载流程区分传输、复用、校验和安装处理，恢复任务时沿用已有完成量，支持单文件失败重试。
- 下载列表优先显示正在传输的文件，其后按最近完成顺序排列；并发上限提高至 256，改进自适应并发和停滞连接的重试处理。
- 游戏意外退出时展示崩溃诊断与相关日志；改进 Log4j XML 日志的显示。
- 为符合条件的早期 Minecraft 版本自动下载兼容性补丁，处理 Apple Silicon 上的红蓝反色问题。

## 账户与皮肤

- 登录后仍可选择游客启动，支持修改游客名称与选择皮肤；内置 Steve 和 Cirno 皮肤，自动缓存登录账户皮肤并合并重复项。
- 登录账户可应用所选皮肤、修改 Minecraft Java 版名称；改名失败时保留错误提示和输入内容。
- 首页皮肤加入轻微肢体动画、切换账户的轮盘过渡，以及单击压扁、双击摸头和爱心粒子效果。
- 复用当前会话凭据，减少重复访问系统凭据存储；macOS 本地开发支持固定自签身份，减少每次重新编译后的钥匙串授权提示。

## 界面与发布

- 调整资源卡片、配置编辑、状态图标及列表切换动效，保持界面紧凑。
- 提供 macOS Apple Silicon、Windows AMD64、Linux AMD64 安装包和签名更新产物。
- macOS 发布包仍使用 ad-hoc 签名，Windows 发布包尚无发布者代码签名；本地自签证书不会上传至发布流程。

这是预发布版本。
