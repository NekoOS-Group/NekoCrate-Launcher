# dev0.9.8

扩展游戏目录、版本与资源的拖入和导出操作，统一安装执行与恢复流程，并精简程序和图片资源体积。安装版与便携版共用同一可执行文件。

## 拖入、复制与导出

- 包含 `.minecraft` 的完整实例 ZIP 可直接拖入窗口，选择名称和存放位置后导入；包含多个游戏目录时先选择目标，不覆盖已有目录。
- 拖入 `versions` 或其中的版本目录，可关联所属游戏目录并选中版本；拖到指定实例或版本条目可复制到目标游戏目录，保留源文件并检查同名冲突。
- 复制版本时带上已存在的基础版本及引用依赖，缺失依赖保留为待下载状态；需要外部工作目录的版本会提示关联原目录。
- 混合拖入资源时按实际内容分类并预览，数据包可指定存档；拖入 Modrinth / CurseForge 项目链接可打开详情和兼容版本选择。
- 配置文件可拖入当前配置编辑器，比较内容后保存；拖动时自动展开实例折叠区与版本列表，补充资源到达反馈。
- 支持导出游戏目录或版本 ZIP，可附带当前平台的便携启动器；不导出账户凭据及启动器个人数据。

## 安装与体积优化

- 游戏、加载器、整合包、资源及 Java 安装复用安装计划和执行流程，统一下载、校验、解压、提交及恢复处理。
- 合并重复的任务状态与持久化机制，安装处理使用实际完成记录恢复，避免重复维护两套步骤状态。
- 启用跨依赖链接优化，按平台分离诊断符号；精简重复的序列化、异步任务与排序代码，减少不需要的 Tauri 权限及构建输出。
- 移除旧图集，苔石改为 Minecraft 原版纹理，界面图标改用适合显示尺寸的图片资源，保留已有实例图标设置。
- Linux 使用系统 D-Bus 运行库；DEB 声明对应依赖，独立 ELF 仍需系统提供 GTK、WebKitGTK 与 D-Bus。

## 发布文件与升级

- Windows：安装包为 `-win-amd64-setup.exe`，独立程序为 `-win-amd64.exe`。
- Linux：提供 DEB 安装包及独立 `.elf`。
- macOS Apple Silicon：提供 DMG 安装包，以及合并后的唯一 `.app.tar.gz`，不再区分两个 App 压缩包。
- 独立程序文件名不再包含 `portable`。没有安装模式配置时，程序使用所在目录的 `.minecraft` 和 `.nekocrate`；安装包会部署配置，继续使用系统应用数据目录。CLI 与开发模式行为不变。

**此前发布的 macOS 客户端及 Windows 便携客户端需要手动替换一次。** macOS 安装版用 DMG 覆盖原 App；便携版仅替换程序，保留旁边的 `.nekocrate` 与 `.minecraft`。Windows 安装版与 Linux ELF 的更新入口不变。新版本继续验证自动更新签名，macOS 安装模式会在后续通用包更新中保留。

macOS 开发包使用 ad-hoc 签名，尚未进行 Apple 公证；Windows 开发包尚无发布者代码签名。
