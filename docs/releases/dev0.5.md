猫咪盒子启动器 dev0.5，应用版本 `0.5.0-dev.1`。

## 游戏与运行环境

- 支持启动已有 Fabric、Forge、NeoForge 版本，并支持安装 Fabric；子实例菜单显示游戏版本与加载器版本。Forge、NeoForge 的安装暂未提供。
- 解析版本继承、HMCL 合并配置和整合包的隔离目录，使用原目录中的模组、配置与存档。
- 根据游戏、加载器和模组约束匹配 Java，优先复用兼容的本地 JDK；有明确兼容依据时允许更新的 Java，缺少依据时保留游戏要求的主版本。
- 修复部分旧版整合包在 macOS 上的 JNA、OpenAL 原生库兼容问题，保留原始版本元数据。
- 启动内存支持最小、推荐、自动与自定义，默认自动；自动模式按启动时的可用内存计算，同时检查 Java 位数和整合包声明。

## 实例与界面

- 将文件夹拖入窗口，可在后台扫描隐藏的 `.minecraft` 并原地关联。默认名称使用上层文件夹名，重复目录不会重复添加。
- 单个实例直接关联，多个实例才打开选择列表；未找到实例时仅在右上角提示。关联提示显示名称和路径，2 秒自动消失。
- 拖动已有实例时，右上角出现垃圾桶，放入即可移除。关联的原游戏目录保留；托管实例沿用移至回收目录的行为。支持单实例拖动，移除失败时图标自然归位。
- 修正方块图标的投影比例，调整网络设置下拉选项高度。

## 日志

- 双击运行中的实例打开对应日志，游戏意外退出时自动展示日志。
- 区分并高亮日志等级，整理重复时间戳，支持实例、等级及文本筛选。
- 保留本次启动器会话的完整日志，通过虚拟列表和批量更新减少渲染开销；复制可包含完整筛选结果。

## 安装与后续更新

- 安装 dev0.5 后，支持应用内下载更新、验证签名、安装替换并重启。游戏运行或其他任务进行时暂不安装更新。
- **dev0.4 及更早版本需手动安装一次 dev0.5**，之后才具备应用内安装更新能力。开发模式和 Linux DEB 仍使用手动安装入口。
- 提供 macOS Apple Silicon 的 DMG / app ZIP、Windows AMD64 的 EXE，以及 Linux AMD64 的 AppImage / DEB；另附更新包、签名、`latest.json`、`SHA256SUMS` 和 `BUILDINFO.json`。
- 发布继续复用同一提交通过 CI 的前端产物与跨版本 Rust 缓存，并检查各平台安装包、架构和更新签名信息。

保留现有账户、实例与设置，不搬移已关联的游戏目录。macOS 包采用临时签名，未公证；Windows 包未做发布者签名。
