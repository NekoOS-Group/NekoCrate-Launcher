猫咪盒子启动器 dev0.7.1，应用版本 `0.7.1-dev.1`。

## 修复 Windows 启动闪退

- 修复 dev0.7 在 Windows 上处理首次界面请求时因线程栈溢出而立即退出的问题（异常码 `0xc00000fd`）。将大型异步任务状态放到堆上，命令入口不再按值传递整个安装状态。
- 发布验证在已编译的三平台程序上检查命令入口的异步对象大小，复用现有内嵌前端检查，不增加重复编译。
- 提前记录启动阶段、数据目录初始化错误和 Rust panic。日志保存在数据目录的 `logs/launcher.log`；目录不可写时尝试系统临时目录下的 `NekoCrate-diagnostics/logs/launcher.log`。原生栈溢出等系统异常仍可能绕过 Rust panic 日志。

## 统一网络依赖

- 游戏下载、Microsoft 登录、元数据请求与自动更新统一使用 `reqwest 0.13.5`，移除旧的 `reqwest 0.12` 及不再需要的依赖。
- TLS 继续使用 `ring`，显式初始化加密提供者，Core / CLI 无需依赖自动更新模块先运行。证书信任使用与更新器一致的系统证书验证。
- 保留登录表单、HTTP / SOCKS 代理认证、流式下载、断点续传和证书错误诊断；继续验证 HTTPS 证书与更新包签名。

## 安装与更新

- 提供 macOS Apple Silicon、Windows AMD64、Linux AMD64 安装包和自动更新产物。
- 若 Windows dev0.7 已无法打开，请手动下载本版本安装包，覆盖安装到原位置；无需删除启动器数据或游戏目录。

这是预发布版本。macOS 包未公证，Windows 包未做发布者签名。
