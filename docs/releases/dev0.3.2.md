猫咪盒子启动器 dev0.3.2，应用版本 `0.3.2-dev.1`。

## 启动修复

- 修复 dev0.3.1 安装后只显示 `index.html not found`：CI 前端产物原先多解压了一层 `ci-frontend` 目录，现直接放入 Tauri 的前端根目录。三平台共用的打包流程一并修正。
- Rust 编译前检查入口 HTML 与其脚本、样式资源；编译后用实际发布程序执行 `--verify-frontend`，验证页面确实已内嵌。检查不打开窗口、不读写用户数据，也不额外编译测试程序。

## 发布优化

- 标签只触发调度，原生编译在默认分支的 workflow 上运行，始终检出标签对应的确切提交；后续版本可复用同一分支的 Rust 发布缓存，不再隔离在各个标签下。
- 桌面端只生成 Rust 库及最终程序，移除未使用的移动端静态库、动态库输出。
- CI 测试不生成调试符号；完整测试、Clippy 和前端构建仍各执行一次，发布继续复用同一提交通过 CI 的前端产物。
- 保留三平台安装包、架构、来源提交和 SHA-256 校验。

本版保持原有渲染方式，用于与后续 dev0.3.3 比较。更新功能目前会检查新版本并提供对应平台安装包的下载入口，安装仍需手动完成。

## 安装

dev0.3.1 无法打开的用户请从本页手动下载。安装包文件名前缀为 `NekoCrate-Launcher-dev0.3.2-`：macOS Apple Silicon 使用 DMG，Windows AMD64 使用 EXE，Linux AMD64 使用 AppImage 或 DEB。

保留原实例、账户与设置；本版没有游戏数据迁移。macOS 仍为临时签名、未公证，Windows 仍无发布者签名。
