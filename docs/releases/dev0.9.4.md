# 猫咪盒子启动器 dev0.9.4

新增 macOS Apple Silicon、Windows x64、Linux x64 便携包。文件名以 `-portable.zip` 结尾，完整解压即可运行；安装版继续保留。两种发行方式使用同一次编译得到的程序。

- 首次启动自动关联程序旁边的 `.minecraft`，不存在时创建空目录。一个游戏目录可以管理多个版本，不复制已有游戏文件，也不自动添加系统里的其他游戏目录。
- 设置、主题、所选实例、索引、Java 和未完成任务保存在旁边的 `.nekocrate`。内部路径随整个文件夹移动，外部手动关联的目录仍保留原位置。
- 安装版和便携版各自保存设置；同一游戏目录的修改操作通过系统文件锁协调，游戏运行期间也持有锁。临时锁不写入游戏目录。
- Windows 便携版更新使用签名验证后的便携包，退出后替换程序并重新打开，不启动安装器。替换或启动进程失败时恢复旧程序；macOS 和 Linux 沿用原有签名更新。
- 发布流程增加三份便携包，不增加 Rust 编译次数；原生检查覆盖便携启动和移动目录后的再次启动。

## 使用说明

关闭启动器后，请移动整个 `NekoCrate` 文件夹，包括 `.minecraft`、`.nekocrate` 和 `nekocrate.portable.json`。不要直接从压缩包或只读目录运行。

Windows 仍需要 Microsoft WebView2 Runtime。Linux 使用 AppImage，需要系统支持其运行环境，并可能需要给文件添加可执行权限。macOS 的 `.minecraft` 位于 `.app` 旁边；若系统临时隔离应用运行位置，会明确提示移动应用并保留旁边的便携标记，不会悄悄改用安装版数据。

登录和代理凭据仍保存在当前电脑的系统凭据库，不随便携包携带。相同电脑移动目录保留凭据标识；换电脑需要重新登录。跨系统或不同架构移动后，Java 需要重新匹配。系统生成的临时文件、凭据及诊断记录不属于便携目录。
