猫咪盒子启动器 dev0.9.1，应用版本 `0.9.1-dev.1`。

## CurseForge

- 官方构建内置应用凭据，可直接搜索整合包、解析依赖和下载文件，无需用户填写 API Key。
- 移除网络设置中的密钥输入、整合包页面的配置入口及相关提示；导入整合包后直接进入安装流程。
- 保留网络错误、限流和作者限制第三方分发的提示；需手动补齐的文件仍可在下载流程中处理。
- 构建凭据通过 GitHub Actions Secret 注入；本地 `cargo ui` 支持读取 Git 忽略的 `.env`。

## 构建与发布

- 前端完成测试和构建后立即提供产物，让三平台发布编译与剩余 CI 检查重叠；只有同一提交的完整 CI 和全部平台构建成功后才公开发布。
- 按操作系统、架构、Node 和锁定的 Tauri CLI 版本缓存已安装 CLI 与打包工具，减少重复安装和下载；工具缓存纳入自动清理。
- 发布缓存保留编译好的依赖，不再保存每次版本更新都需重编译的项目自身产物。
- 分开记录 Rust 编译和安装包打包步骤，打包不重复编译；保存各平台 Cargo 编译耗时报告，便于继续定位慢点。

提供 macOS Apple Silicon、Windows AMD64、Linux AMD64 安装包及签名自动更新文件。这是预发布版本。
