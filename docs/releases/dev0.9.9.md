# dev0.9.9 · 拖动万物的更新

**把资源拖到需要它的版本，把窗口摆到顺手的位置，再给首页添一点自己的风格。**

猫咪盒子启动器 dev0.9.9 来了。这次，我们把「拖动」从文件导入延伸到资源整理、窗口操作和首页布局，让常用操作更直接，也让你的启动器更像你自己的。

## 拖过去，就到位

- **资源流转更顺手。** 从游戏资源或版本管理中，把 Mod、资源包等拖到目标版本，也能拖入新版本的预选资源区；存档支持拖动复制与备份。
- **拖到哪里，先看清再放手。** 落点高亮跟随鼠标平滑变化，减少无关区域的红框干扰；不兼容的资源会说明原因，文件的真实类型不会被落点改变。
- **整理也能用拖的。** 版本内资源、全局收藏副本和启动器托管 Java 可拖到右上角回收区；删除整合包声明的 Mod 前会再次确认。系统 Java 与外部资源仍由原位置管理。
- **窗口不必挡着你。** 工具窗口支持拖动、吸附、调整大小和同时打开，边看版本内容、边整理资源更方便。

## 首页，按你的习惯摆

进入「编辑布局」，账户栏、工具栏、实例栏、启动按钮和主题栏都可以重新摆放。实例栏与工具栏支持横排、竖排，工具按钮可拖动排序、按需增减；布局会记住相邻控件的关系，窗口变大时也能保持整齐。

新的可选小组件，让首页有了更多玩法：

- **服务器列表**：查看在线状态，使用当前选择的版本连接服务器。
- **收藏版本**：把常玩的版本拖进收藏，调整顺序，随手启动。
- **最近存档**：快速找到最近游玩的世界，打开目录或继续整理、备份。
- **待办便签**：记下下一次冒险要做的事，拖动排序，完成后勾掉。
- **像素时钟**：给首页添一块小小的像素时间。
- **一言与 Trends**：一言可切换简洁文字或 Minecraft 风格的闪烁标语，调整字号与角度；Trends 用时间线展示订阅动态，支持贴边收起、悬停展开。

小组件按需添加，已有布局会保留。主题栏可以隐藏；便携模式下，实例栏也可以按需收起。

## 收藏一次，下次直接用

全局资源库现在支持**从已有版本收藏、从外部拖入，以及在线下载**。喜欢的 Mod、资源包、光影和数据包可以先存进盒子，再拖到需要的版本；收藏会保留原文件。

资源缓存的占用条和图例可以直接跳转到对应分类。Java 卡片补充发行版与托管标识，Mod、资源包的图标和长介绍缓存也更耐用，减少重复加载。

## 少一点打断，多一点顺手

- 微软登录改为浏览器账户选择与授权，告别手动抄验证码；账户选择改为紧凑下拉列表，授权临近过期时才自动刷新。
- 实例设置与全局设置改为更紧凑的气泡，实例设置修改后自动保存；导出、修复、移除入口集中在标题栏。
- 加强启动前组件核对、缺失 Mod 前置诊断与修复；修复时显示进度，需要修复的版本可「修复并启动」。
- 修正 Java 发行版版本号、Fabric 版本约束及部分 Mod 元数据解析问题，减少兼容性误判。
- CurseForge 文件节点失效时可回退到另一官方 CDN，404 不再反复请求同一个地址；断点与文件校验继续保留。
- 修复弹窗打开时调整窗口导致皮肤拉伸、部分拖放坐标偏移和控件悬停抖动等细节，继续精简窗口图标与重复生成的代码。

## 下载与更新

本次提供 **macOS Apple Silicon、Windows x64、Linux x64** 三个平台版本，继续支持安装版与独立程序：

| 平台 | 安装包 | 独立运行 |
| --- | --- | --- |
| macOS Apple Silicon | `.dmg` | 解压 `.app.tar.gz` 后打开 `.app` |
| Windows x64 | `-setup.exe` | `-win-amd64.exe` |
| Linux x64 | `.deb` | `.elf` |

从 dev0.9.8 升级可沿用现有更新入口；Linux DEB 请下载安装包更新。独立运行时仅替换程序，保留旁边的 `.minecraft` 和 `.nekocrate`。Linux ELF 仍需系统提供 GTK、WebKitGTK 和 D-Bus。

这是开发预发布版。欢迎通过 [反馈问题](https://github.com/NekoOS-Group/NekoCrate-Launcher/issues) 告诉我们：你还想把什么拖到哪里？
