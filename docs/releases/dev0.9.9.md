# 拖动万物的更新

猫咪盒子启动器 0.9.0–0.9.9 系列更新概述。以下按 dev0.9.9 的当前功能整理，涵盖这一阶段的拖放交互、资源管理、整合包安装、便携运行和界面调整。

## 拖放与批量操作

- 支持拖入游戏目录、包含 `.minecraft` 的实例 ZIP、`versions` 目录及单个版本目录，根据目标位置进行关联、导入或复制。
- Mods、资源包、光影、数据包和存档可拖入对应位置；已有资源可在版本之间复制，也可拖入新版本的资源预选区，或拖出到系统文件管理器。
- 资源支持多选、批量启用／禁用和批量拖动；实例、版本及部分首页列表支持拖动排序。
- 支持将版本和可删除资源拖到右上角回收区。删除使用系统废纸篓／回收站；删除整合包声明的 Mod 前会再次确认。
- 支持导出游戏目录或版本 ZIP，可附带便携启动器，不包含账户凭据及启动器个人数据。
- 拖放提示随目标区域变化，按文件实际内容识别类型；复制保留源文件，并检查同名冲突与兼容性。

## 资源与版本管理

- 新增全局资源管理，集中查看 Java、游戏资源、皮肤和缓存；共享目录中的文件合并展示。
- 全局资源库支持从已有版本收藏、导入外部文件和在线下载，收藏后的资源可再复制到其他版本。
- Mods 支持启用／禁用、查看依赖和编辑关联配置；JSON、TOML、CFG 提供高亮与编辑辅助，保存时备份原文件。
- Mods、资源包和光影支持真实图标、元数据、包内说明及已关联项目的长介绍；在线图文按需加载并缓存。
- Java 管理显示发行版、架构及托管标识，可安装运行时、登记本机 Java 或删除启动器托管的版本。
- 安装完成后清理下载暂存，暂停或失败时保留进度；版本移除后清理对应暂存，本地已索引资源可直接复用。

## 整合包与在线资源

- 接入 CurseForge 官方应用凭据，用户无需自行填写 API Key；支持浏览、下载及导入 Modrinth／CurseForge 整合包。
- 整合包与资源列表采用滚动加载，支持来源、排序、分类筛选，补充作者、下载量、标签、图标及图文介绍。
- 添加游戏版本时可预选多个 Mods、资源包和光影，按游戏版本与加载器筛选，安装时处理必要依赖。
- 整合包依赖批量解析并同步下载，恢复时复用已完成结果；需要手动下载的文件单独列出，其余安装继续进行，下载好的文件可拖入补齐。
- 修复中断安装后部分整合包持续出现版本元数据不一致的问题。

## 窗口、布局与首页

- 工具窗口支持拖动、吸附、调整大小和同时打开。
- 首页布局可编辑，账户栏、工具栏、实例栏、启动按钮及主题栏可调整位置；实例栏与工具栏支持横排／竖排，工具按钮可排序和按需增减。
- 新增可选小组件：服务器列表、收藏版本、最近存档、待办便签、像素时钟、一言和 Trends 订阅动态。
- 一言支持简洁文字和 Minecraft 风格标语，可调整字号与角度；Trends 支持订阅源选择、时间线展示和贴边自动收起。
- 账户选择改为下拉列表，实例设置与全局设置改为紧凑气泡，设置修改后自动保存；统一列表、窗口及控件切换动效。

## 启动、下载与诊断

- 扩大本机 Java 发现范围，统一自动与手动选择的兼容性判断，结合加载器、Mod 约束及历史成功启动记录，减少不必要的运行时下载。
- 完善版本隔离、窗口尺寸／全屏、启动后最小化、日志行为，以及 JVM 参数、游戏参数和环境变量设置。
- 崩溃诊断整合到日志，补充组件清单核对、缺失前置及版本冲突分析，并提供修复、选择 Java、调整内存等处理入口。
- 下载区分传输、复用、校验与安装，支持暂停恢复和单文件重试；并发上限提高至 256，改进自适应并发及停滞连接处理。
- CurseForge 下载失败时可切换官方 CDN，404 不再反复请求同一地址；继续保留断点与哈希校验。
- 修复部分 Java 版本号、Fabric 版本约束和 Mod 元数据解析问题，并为符合条件的旧版 Minecraft 自动应用兼容性补丁。

## 账户与皮肤

- 微软登录改为浏览器授权与账户选择，不再使用设备验证码登录；有效会话复用，临近过期时自动刷新。
- 登录后仍可选择游客启动，游客支持修改名称和切换皮肤；登录账户支持修改 Minecraft Java 版名称与皮肤。
- 内置 Steve 和 Cirno 皮肤，登录账户皮肤自动缓存；首页模型增加轻微肢体动画、账户切换过渡、点击反馈与爱心粒子效果。

## 便携运行与发布

- 安装版与独立程序共用同一可执行文件。独立运行默认管理程序旁的 `.minecraft`，设置、Java 和任务保存在 `.nekocrate`；安装版使用系统应用数据目录。
- Windows 提供安装 EXE 和独立 EXE；Linux 提供 DEB 和独立 ELF，不再发布 AppImage；macOS Apple Silicon 提供 DMG 和统一的 `.app.tar.gz`。
- 自动更新保留签名与版本验证。签名并入更新清单，文件校验信息集中在 `BUILDINFO.json`，不再提供独立 `.sig`、`.app.zip` 和 `SHA256SUMS`。
- 统一安装计划与恢复记录，减少重复执行逻辑；精简重复生成的代码、窗口图标和图片资源，并复用构建缓存与前端产物。

本系列仍为开发预发布版本。dev0.9.7 及以前的 macOS 客户端和 Windows 便携版需要手动替换一次程序；便携升级时保留旁边的 `.minecraft` 和 `.nekocrate`。Linux DEB 通过安装包更新，独立 ELF 需要系统 GTK、WebKitGTK 和 D-Bus 运行库。
