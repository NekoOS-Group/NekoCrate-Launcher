猫咪盒子启动器 dev0.9.2，应用版本 `0.9.2-dev.1`。

## 整合包安装

- CurseForge 依赖改为批量解析，显示已解析数量，并复用已经保存的解析结果。
- 边解析边下载，不再等待全部依赖解析结束才开始下载；恢复任务时保留已完成的进度。
- 遇到作者限制第三方下载的文件时，继续自动安装其余资源，在任务界面提供手动下载和导入指引。
- 可将下载好的文件拖入手动导入区域。其他安装步骤完成后，任务停留在「手动导入文件」步骤；此时点击下载并启动会打开任务窗口。

## 拖放交互

- 拖动已有 Mod、资源包或光影时，使用现有版本列表、实例图标和折叠区选择目标，移除额外的「复制到版本」面板。
- 拖入提示统一使用随目标范围变化的虚线框；ZIP 按内容识别类型，目标不匹配时就地说明原因，不自动转投其他位置。
- 手动导入区域只接收拖到该区域的文件，不再截获拖向其他版本的资源。
- 接入向系统文件管理器拖出 Mod、资源包、光影、数据包和存档的功能，采用复制方式，保留游戏中的原文件。原生拖出交互仍需更多跨平台实机验证。

## 启动与日志

- 崩溃诊断写入游戏日志，与退出信息一起显示，移除单独的诊断面板。
- 补充 Java 模块冲突和异常链的诊断线索。
- 修复整合包版本别名影响 Forge 启动忽略列表的问题。

## 已知问题

- macOS 本地开发版使用自签证书时，重新编译后仍可能再次要求钥匙串授权；固定自签证书不能保证跨构建免授权，此版本尚未解决这一问题。

提供 macOS Apple Silicon、Windows AMD64、Linux AMD64 安装包及签名自动更新文件。这是预发布版本。
